# Basic Chatbot

This is a simple chatbot made using Python as part of my CodeAlpha internship.

## About

The chatbot can have a basic conversation with the user. It recognizes some common messages and gives suitable replies.

It can also show the current time.

## Features

- Responds to greetings
- Responds to common conversations
- Tells the current time
- Handles simple questions
- Allows the user to exit the chat

## How to Run

Make sure Python is installed on your computer.

Open the project folder in VS Code and run:

python chatbot.py

Then type a message and press Enter.

To close the chatbot, type:

bye
